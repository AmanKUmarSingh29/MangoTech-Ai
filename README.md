# MangoTech AI 🥭

MangoTech AI is an AI-powered study companion designed to help students learn more efficiently using Artificial Intelligence and Natural Language Processing (NLP).

The platform allows users to upload study notes in PDF format, generate AI-powered summaries, create quizzes automatically, and analyze learning performance through intelligent topic tracking.

---

# 🚀 Features

## 📄 PDF Upload & Analysis
Upload study notes or documents in PDF format for AI-based processing.

## 🧠 AI-Powered Summarization
Generate concise and meaningful summaries from lengthy study material.

## ❓ Automatic Quiz Generation
Create practice questions automatically from uploaded notes.

## 💬 Context-Aware Q&A System
Ask questions based on uploaded material and receive intelligent answers.

## 📊 Study Performance Analytics
Track learning performance and monitor topic-wise progress.

## 🎯 Weak Topic Detection
Identify weak concepts based on quiz performance and incorrect responses.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/AmanKUmarSingh29/MangoTech-Ai.git
```

---

## 2️⃣ Navigate to Backend

```bash
cd MangoTech-Ai/backend
```

---

## 3️⃣ Create Virtual Environment

### Windows
```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac
```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run FastAPI Server

```bash
uvicorn app.main:app --reload
```
