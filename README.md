# MangoTech AI 

MangoTech AI is an AI-powered study companion that helps students learn smarter by:
- Summarizing study material
- Generating questions
- Answering queries using uploaded notes

---

## 🚀 Features
- 📄 Upload PDF notes
- 🧠 AI-based summarization
- ❓ Question generation
- 💬 Context-based Q&A (coming soon)

---

## 🧠 Tech Stack
- Backend: FastAPI (Python)
- AI/NLP: HuggingFace Transformers
- Vector DB: FAISS (planned)
- Frontend: Streamlit / React (planned)
